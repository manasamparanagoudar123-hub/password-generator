#  Password Generator

A simple random password generator built using Python.

##  Features

- Generate random passwords
- Choose the password length
- Includes letters
- Includes numbers
- Includes special characters

##  Technology Used

- Python

##  How to Run

1. Open `password_generator.py`
2. Run the program in Python
3. Enter the required password length
4. Copy the generated password

##  Python Concepts Used

- Variables
- User input
- `for` loop
- `random` module
- `string` module
- Strings
- `random.choice()`
